Digital employee register for **LaPetite Chemists Ltd**, Plot 8 Block J, Ahodwo, Kumasi.

## Open in the browser

https://raw.githack.com/MEFolson/lapetite-staff/main/index.html

Access code: `Ahodwo2026`

## Download a copy

https://github.com/MEFolson/lapetite-staff/archive/refs/heads/main.zip

1. Download and extract the zip.
2. Open `index.html` in Edge, Chrome or Safari.
3. Enter the access code.

Records stay in that browser. Use Settings to export a backup.

Change `const PIN` in `js/app.js` before live use.
